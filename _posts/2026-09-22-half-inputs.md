## Half Inputs
### Mocking a Button and Switch 

---


In this Arduino coding assignment, the expectation was to assign a value to button and switch using boolean operators. We had to assign a different LED turning on depending on the combination of button and switch being on or off. We used a combination of !btn, !swt, btn, and swt to mimic this. 

I used logical operators rather than nested conditionals for this assignment, as I was used to the formatting of logical operators. However, I believe nested conditionals would make more sense for this assignment, as it involves four different possible combinations. The more possible outcomes there are, the code will be easier to read and write if you use nested conditionals over logical operators. 

One tip I would give to myself before starting this assignment is to not get stuck on the equal sign. It is easy to see it and quickly think it means equal, but it just is assigning a value.
