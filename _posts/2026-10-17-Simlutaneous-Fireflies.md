## Simultaneous Fireflies 

---


In this E-Textiles assignment, we combined three different firefly flashing patterns into a single file. The first firefly pattern was called  Big Dipper, where a light flashed every 3 seconds, starting at 0 and growing linearly by 30 every 0.1 seconds until max brightness, and then turned off. The second firefly pattern was called Flash Bulb, where a light flashes brightly for 0.5 seconds every 4 seconds, starting at second 0. The third firefly pattern was called Blue Ghost, where there was a consistent light that randomly fluctuated between barely glowing to full light, randomly moving up or down by 50 every 0.5 seconds.

If I had to give a tip to others for attempting this project for the first time, I would definitely recommend to add comments besides each code to differentiate which firefly the code is referencing to. I would also recommend change certain variable names to correspond to the firefly, for example BG brightness (blue ghost brightness) instead of just brightness.
