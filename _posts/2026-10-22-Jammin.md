## Using The Buzzer 
  

---


In this E-textiles assignment, we had to play a song on the LilyPad buzzer when a switch was turned on, and and when the switch was turned off, the song had to stop playing.

I chose "Shape of You" by Ed Sheeran, and I found the code on the Arduino website.

To make this code play in a loop, I used an if statement within the loop. If the button was pressed,
the song would play, as the code for the song playing happens under "if SwtValue == LOW".

One tip I would give my past self before starting this is to understand that Arduino doesn't know what C,D,E or any of the notes
are and I need to manually define the value for each note.
