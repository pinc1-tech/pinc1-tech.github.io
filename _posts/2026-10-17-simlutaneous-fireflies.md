## Responsive Buttons

---


In this E-Textiles assignment, we had to use Arduino and a LilyPad to turn on a different LED every time a button was pressed again. The light had to remain on while the button was pressed and turn off when the button was released. 

#### Three tips I would give my past self:

- I would add comments that describe what the code is doing as I wrote the code. The comments help me understand exactly what is going on and what I need to do next the successfully complete the requirements of the assignment.

- I would remind myself that if, else if, and while statements do not need semi colons but instead need brackets.

- I would remember that I set the variables so that when the button is "HIGH," it is released, and when it is "LOW," it is pressed. Having these variables consistent throughout my code is what makes it work!
