
 
### Arrays!



In this E-Textiles assignment, we had to use arrays to turn on a random PWM pin to a random brightness every second. If the PWM pin that was chosen randomly
is already on, we had to turn it off. 

![Baby Seal](https://pinc1-tech.github.io/assets/img/images-2.jpeg)


If I had to give a tip to my past self when starting this project, I would make sure to only use one bool state. I initially had one for true and one for false,
but that is unnecessary, as there are only two conditions so I don't have to use more than one bool state and I can just use "else".
